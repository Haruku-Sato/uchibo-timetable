# 段階6：千葉〜津田沼（総武線）と蘇我〜新習志野（京葉線）の追加

この2区間は通常ダイヤで運転している。時刻は JR東日本の公式時刻表（2026年10月版、timetables.jreast.co.jp）の
**駅の発車時刻**から転記した（チャット側で調査済み）。
列車ごとの途中駅の時刻は集めていないため、**発車時刻＋代表的な所要時間**で着時刻を作る。

## 追加する駅
- 総武線：千葉 — 津田沼（途中駅は扱わない）
- 京葉線：蘇我 — 海浜幕張 — 新習志野
  - 海浜幕張を入れる理由：日中の京葉線は、快速が新習志野を通過し、普通は海浜幕張止まりが多い。
    そのため、蘇我〜新習志野は海浜幕張で乗り換える経路が必要になる（特に土休日の日中は、直通の普通がない）。
- 千葉と蘇我は既存の駅。内房線の臨時ダイヤの列車と、乗換余裕を取って乗り継げるようにする。

## 列車の作り方
- 下の各表の1つの時刻を1本の列車とし、`発車駅の時刻 → 到着駅（発車時刻＋所要）` の connection を作る。
- 蘇我→新習志野の普通は、1本の列車として「蘇我 → 海浜幕張（+13） → 新習志野（+17）」と作る（乗り換えなし）。
  新習志野→蘇我の普通（蘇我まで行く便）も、「新習志野 → 海浜幕張（+5） → 蘇我（+17）」の1本の列車にする。
- 京葉線の同じ列車が、別の駅の表に重ねて載っている（例：新習志野発の普通が、海浜幕張の表にも載っている）。
  これは別の列車として作ってよい。同じ時刻になるだけで、経路の結果は変わらない。
- **特急（特NEX、特し、特あ、特富、特わ、特さざ、特新さ、特蔵茂など）は入れない**（特急券が必要なため）。
- 快速は京葉線の新習志野を通過する。蘇我を出る快速は海浜幕張まで、新習志野→海浜幕張の区間は普通だけにする。
- 行き先の記号（君、空、一、佐、成 など）は、その駅より先の行き先を示しているだけ。表の区間は全列車が停車する。
  ただし、「新習志野 下り」の **幕＝海浜幕張止まり** は、蘇我へ行かない。
- 「◆＝運転日注意」の便も入れる（正確な運転日は扱わない）。
- 0時台は24時以降として扱う（既存の `tm()` と同じ）。
- 平日と土休日で別のデータを持ち、既存の平日／土休日の切り替えに合わせる。

## 画面
- **検索画面**：駅の選択に、総武線（津田沼）と京葉線（海浜幕張、新習志野）の駅を、別のグループとして追加する。
- **路線図**：
  - 千葉から北西へ「津田沼」の枝線を描く。
  - 蘇我から湾岸沿いに北西へ「海浜幕張 — 新習志野」の枝線を描く。
  - 2本とも、内房線と区別できる線（例：細い灰色の線か、路線ごとの色）にする。
  - 路線図の上の方に十分な余白を取り、重なりチェックの対象に含める。
- 追加区間の時刻は推定なので、検索結果では着時刻に「頃」を付け、路線名（総武線各駅停車、総武線快速、京葉線、京葉線快速）を表示する。
- 説明文に「千葉〜津田沼・蘇我〜新習志野は通常ダイヤ（JR東日本 2026年10月の時刻表）。着時刻は代表的な所要時間からの推定」と書く。

## テスト（バス25分・乗換余裕2分・平日）
- 津田沼→千葉：10:05発の快速は、千葉に10:16に着く。
- 千葉→津田沼：平日12:02発の快速は、津田沼に12:12頃着く。
- 新習志野→蘇我：平日11:13発の普通は、蘇我に11:30頃着く（直通）。
- 新習志野→蘇我（**土休日**の12:00以降）：直通の普通がないので、海浜幕張で乗り換える経路が出る（普通 12:04 海浜幕張行 → 快速 12:18 など）。
- 蘇我→新習志野（**土休日**の11:00以降）：快速で海浜幕張へ行き、普通に乗り換える経路が出る。
- 君津→津田沼：平日の朝（例：10:00までに着く）に経路が出て、千葉で乗り換える。
- 君津→新習志野：蘇我で京葉線に乗り換える経路が出る。
- 既存のテストが、すべてそのまま通ること。
